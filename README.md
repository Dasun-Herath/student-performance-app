# 🎓 Student Performance Analyzer

A web-based **Student Performance Analyzer** built with Python and Streamlit to help students understand their academic performance through marks analysis, performance insights, personalized study recommendations, and progress tracking.

## ✨ Features

* 📊 Student marks analysis
* 🧮 Automatic average calculation
* 🏆 Performance and grade evaluation
* 💪 Strong and weak subject identification
* 🔔 Smart performance alerts
* 📚 Personalized study recommendations
* ▶️ Learning resources and YouTube suggestions
* 📈 Student progress tracking
* 🔐 User login and registration
* 🏅 Points and leaderboard features
* 🤖 AI-powered assistance
* 📱 User-friendly web interface

## 🛠️ Technologies Used

* **Python**
* **Streamlit**
* **Pandas**
* **Firebase**
* **Pyrebase4**
* **OpenAI API**

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Dasun-Herath/student-performance-app.git
```

Go to the project folder:

```bash
cd student-performance-app
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## 🎯 Purpose

The main purpose of this project is to provide students with a simple and interactive platform to analyze their academic performance and identify areas that need improvement.
